# filtered265报告口径与输出说明

这是报告模板与字段说明，尚不代表265题已全部推理。真正完成数、已执行数、预算停止数和分母由最终 `filtered265/evaluation_summary.json` 生成。

固定范围为四项规则和历史隔离后265题，173仓；用户允许重复仓库。旧100复用44题，新分配221题。四规则均不放宽；没有以函数目标数或结果好坏选题。该集合不是原生固定300题、不是原Lite300，也不保证与Lite同难度。

| 字段/行 | 含义 |
|---|---|
| `allocated_n` | 该固定组全部分配题数，不随成功率改变 |
| `population_n` | 当前行纳入的统计人口；allocation/执行/HTTP人口不同 |
| `executed_n` / `http_attempted_n` | 真实启动或终态 / 有实际HTTP尝试证据的题数 |
| `not_run_n` | 尚无执行结果的题，不叫模型答错 |
| `budget_stopped_n` | 已执行但预算中止的题，保留该人口内已知可评分母 |
| `input_preparation_failure_n` | 最终准备失败；初次已同ID修复的历史失败不在此重复计数 |
| `model_or_output_failure_n` | 执行或输出失败，与预算/准备/未运行分别列示 |
| `function_evaluation_status_counts` | 非空完整、空、INCOMPLETE、evaluation_unavailable分别统计 |
| `file_denominator` / `function_denominator` | 各级别、各人口已知可评的实际分母，不硬写265/221 |
| `allocation_*_eligibility_unknown_n` | 准备或评价不可用导致尚不能确认的目标资格；不当NA空集 |
| `score_semantics` | 有未运行项时allocation值是完成信用下界，executed值才是已执行子组成绩 |
| `*_hit_5_allocation_uncertainty_bounds` | 固定可评分母中，未运行项导致的Hit5上下界；不是bootstrap CI |
| `*_ci95` | 固定seed、10000次issue与repo-cluster bootstrap95%区间 |
| `previously_observed_repository_n` | 同组中曾出现在旧100元数据的仓库数；新题不等于新仓 |

逐题NOT_RUN指标始终是NA。allocation汇总的零信用是保守下界，不把这部分题称为实际模型失败；该下界的CI也不能代替未执行不确定性。已执行失败、截断或预算停止不会因为无有效定位被删掉。执行子组的分母不能冒充全部新221。

函数采用冻结严格path::qualified_name身份，包括外层类/函数名。无效、重复项保留原位置，Precision@k固定除k；recall按唯一gold函数集合，AllCoverage要求覆盖全部既有目标。空金标与合法空输出不同。文件真值为补丁涉及的既有非测试Python文件，函数真值只覆盖既有具名函数；缺少金标或索引不记为空集。

逐目标源码送达需要同时有：base内容/定义区间核验、保存的源码块、包含这些块的实际最终request，以及匹配该request的成功HTTP回执。单有输入hash不推断送达；完全/部分可见和未送达分别保留。自动诊断不声称知晓模型注意或推理过程，人工语义复核单列。

共享财务baseline保留上一批Lite的原1505条记录与$3.24130776保守占用；总cap仍为$5。费用表区分本池新增请求、旧44历史复用、原基线与无法关联/未知费用的条目。旧复用不再扣账，不以新run重置额度。usage估算、峰时无缓存标准化和保守账本额不是相同口径，也不是账户账单。

资源分布仅描述实际执行/HTTP题中的已知样本，报告n、mean、median和P90。未知token/费用不填0；存在未知时只能引用known subtotal。墙钟含API等待和方法内源码/grep处理，不含排队、预备全量SHA与离线gold。进程CPU秒、准备wall及GPU用量各自独立。

本批所有gold_patch_pass与empty_patch_fail均NOT_CHECKED；不声称官方harness通过或完全CQ2资格。首次错误查主盘守卫的151题准备失败及同ID恢复见[工程修订记录](preparation_guard_scope_revision.json)；该工程事件无API且不变更固定名单，不能把初次失败当作最终151次定位失败。

正式运行后，中文总览、逐题分析及四张CSV由报告程序生成。CPU报告复现命令见根目录[README_报告复现.md](../README_报告复现.md)。旧Lite270与原external100继续按其独立范围保存，不在此混合汇总。

同QN多span时，`final_delivered_any_definition_full`仅表示任一同名定义span已到达；新增的`modified_base_span_delivery_evidence`与`actual_modified_implementation_verified`另据r2实际匹配base span证明修改体是否全部完整送达。same-leaf不同path/QN另记附证，不能据此自动改名或认定心理原因。完成输出后的严格未命中与工程/预算/输出失败分节，Top5命中但未全覆盖另节。
