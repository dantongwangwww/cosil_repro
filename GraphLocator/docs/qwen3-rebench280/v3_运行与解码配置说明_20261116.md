## 变更依据与范围

v2在少量运行中出现连续8192-token的length结束及高度重复的CIG行结构；这提示特定模型与解码设置的适配风险，不能据此证明greedy是唯一原因。详细原始时间范围、逐响应计数及工程停止事实见[pre-v3记录](v2_长生成快照与v3解码适配预变更记录_20261116.md)。v2退休时是4complete、1operator-interrupted、15未启动；没有v2整批准确率，不能把操作中断当模型失败。

本轮核对同一固定权重revision的[Qwen3-8B官方模型卡](https://huggingface.co/Qwen/Qwen3-8B/blob/b968826d9c46dd6066d109eabc6255188de91218/README.md#L353)，采用其非思考推荐temperature=0.7、top_p=0.8、top_k=20、min_p=0。每请求显式seed=0是本实验固定项，不是官方建议，也不保证并发或不同后端绝对确定。模型卡反greedy的强措辞位于思考模式段，不能扩写为非思考模式的禁令。没有扫penalty或根据定位成绩搜索其他参数。

v3仅调整该解码profile，并修复评价文本中固定写temperature=0的元数据问题。模型权重、搜索/因果prompt、候选与源码、CIG算法及因子/插入次序排名、定长布尔schema、公开AST312身份解析均沿用v2；报告元数据变化不影响冻结评分器、统计方法、Gold、历史reference或预测槽。

```bash
source .venv/bin/activate
python -m unittest discover -s rebench_qwen3 -p 'test_*.py' -v

  --run experiments/qwen3_rebench280_v3_20261116 --phase pilot20 \
  --workers 2 --runner-timeout 1800 --graph-wait-seconds 7200 --poll-seconds 5

  --run experiments/qwen3_rebench280_v3_20261116 --scope pilot20 \
  --output experiments/qwen3_rebench280_v3_20261116/reports/pilot20_NEW
```
