# GraphLocator＋Qwen3同题评估说明

本轮只评估同一冻结280题池的固定前20题金丝雀，或明确指定的完整280题；两个scope分别出报告，绝不将20题预测与280题历史总分混用。父池按历史结果事后构成，具有选择偏差，属于开发比较，不是独立盲测。

## 入口与先终态后金标

在GraphLocator根目录运行：

```bash
source .venv/bin/activate
python -m unittest rebench_qwen3.test_evaluate -v
python -m rebench_qwen3.evaluate \
  --run experiments/qwen3_rebench280_v1_20261115 \
  --scope pilot20 \
  --output experiments/qwen3_rebench280_v1_20261115/reports/pilot20_NEW
```

`--scope full280`要求全部280题终态；`pilot20`必须是`selection/manifest.json`完整280条记录的同序前20条，并由`selection/pilot20.json`绑定完整manifest SHA。输出目录必须新建，已有报告不覆盖。

尚未全部scope终态时，入口只读取名册、真实worker结果及usage/runner回执，输出进度与已发生资源，不打开`private/evaluation_sources.json`、Gold、库存或历史预测，不计算暂时准确率。缺结果、未终态与失败分别保留；terminal失败在最终固定分母中按空排名计分，不用内部partial CIG或额外调用补答案。

全部scope终态后，才读取`private/evaluation_sources.json`中的精确绝对路径和SHA，绑定已冻结的LocAgent FINAL280评价源：Gold、inventory、comparison及reference_evaluation。完整280的instance_id/repo/base一致性、R2目标、输入SHA及冻结评分器SHA均核对后，再按当前scope的ID投影。

## 四臂与严格评分

三个历史条件为CoSIL-Qwen3、CoSIL-SFPruner及LocAgent统一解析；它们复用上一轮FINAL280中的同ID最终槽位、状态、逐题原值和已有资源，不能按胜负另选版本。新增第四臂为本轮GraphLocator兼容版。四臂分母完全相同，只有当前scope的20或280题，95%区间在该scope重算。

统一调用`CoSIL/papers/SFPruner/specprune/evaluation.py`，SHA256固定为：

`22b6c4c8c24da8b88bc09c0191ffe830d5ba375183e1d98c00577007adffe5aa`

GraphLocator只读取worker的`found_files`和`found_entities`。函数身份必须为真实相对路径与限定名组成的`path::qualified_name`；只作无损语法转换，再由修复前库存严格校验。不以Gold消歧、叶名猜测、类方法展开、构造函数补入或压缩排名。`<unresolved_ast:...>`等显式无效身份保留原槽并评为无效；不读取可选alias `found_functions`替换答案。历史槽位也按原位保留。

指标包括文件/函数Hit@1/3/5、Macro-P/R/F1@5、AllCoverage@5、MRR@10。P@5固定除以5；Hit采用Wilson95%CI，宏指标与配对差值采用5000次逐题bootstrap，seed=20261115。三个历史臂分别对GraphLocator计算同题四格、差值区间与精确McNemar；探索性多项比较未校正，未显著不表示等效。

## 结果与资源接口

worker终态为`outputs/<iid>/result.json`，必须含相同instance_id/repo/base_commit、terminal、status、实际usage及最终列表。`complete`允许最终空排名，仍保留状态并按miss评分；`failed`的最终列表必须为空，内部未完成CIG仅作为诊断原件保存。

输出`final_report.md`、`summary.json`、`evaluation.json`、UTF-8 BOM `per_issue.csv`。CSV始终保留scope全部任务；未评分阶段所有指标空白。未知usage/费用不补零，已知token下界单列，历史用量不重新记为本轮支出。worker内部、HTTP生成、工具、构图及runner墙钟分开，有缺项记NA；历史SF的共享文件阶段token不完整，不能直接据表作全流程效率结论。本地API费用0也不表示硬件、电力成本0。

失败类别仅描述执行失败、无候选、文件未命中、文件命中而函数未命中、部分或全部目标覆盖等可观察阶段。没有额外日志证据时，不将所有未命中归为模型不会工具或唯一代码bug。

## 方法解释边界

源码基于当前GraphLocator及Gold-blind通用工具/解析兼容补丁，不冒称逐字官方复现。GraphLocator保留原生CIG因子与插入次序的排序机制，temperature=0单轨迹；LocAgent历史条件为两次temperature=1样本的MRR融合，因此不宣称采样/搜索预算相同。使用通用Qwen3-8B及显式非思考，未替换为作者专用微调模型，不运行DeepSeek付费请求。

本轮不训练、生成修复补丁、运行修复测试、解封训练test或改写历史结果。源码发布只包含代码/文档，原始模型输出、Gold、日志、数据及CSV留本地。
