## 固定模型官方配置依据及措辞边界

已核对本次同一权重revision的[Qwen3-8B官方模型卡](https://huggingface.co/Qwen/Qwen3-8B/blob/b968826d9c46dd6066d109eabc6255188de91218/README.md#L353)：非思考模式建议temperature=0.7、top_p=0.8、top_k=20、min_p=0；Best Practices中也列出同一建议。这是该模式的建议配置。模型卡反对greedy并提及重复的强措辞位于**思考模式**段，不能转写为对非思考模式的严格禁令。

据此登记一个不扫参的解码兼容性处方。重复形态是观察事实，改变解码是否减少重复或改善定位仍须新实验验证，不能由官方建议推导出必然效果。

| 请求配置 | 已冻结v2 | 拟定v3 |

| 模型/权重 | Qwen3-8B固定b968826 revision | 相同 |
| 思考开关 | false | false |
| temperature | 0 | 0.7 |
| top_p/top_k/min_p | 未逐请求显式指定；不猜服务默认值 | 显式0.8 / 20 / 0 |
