# GraphLocator DeepSeek-V4.1-Flash 部署与实验计划

用户配置：DeepSeek 官方 API；模型 `DeepSeek-V4.1-Flash`（API ID `deepseek-flash`）；开启思考 `high`；金丝雀与全量总预算 20 元。密钥存于仓库外的用户配置目录，权限 600，不写入源代码、版本快照、日志或提示词。

## 固定比较配置

采用 Qwen 适配v2 最终选中的 B2（基线推理版本 `fff58180ee7d0c65`）：同一 300 个 SWE-bench Lite issue ID、base commit、图缓存、搜索分页与原版 Mermaid 因果逻辑。七道既有金丝雀验证后再进入全量；同版本的金丝雀结果复用，避免重复支付，不依据命中率选择方案。模型之外的供应商、思考开关、上下文、输出上限与 JSON 协议变化分别记录，不能声称纯模型权重消融。

JSON 请求使用官方 `json_object`，显式传递完整输出 schema，沿用客户端校验和一次格式修复；原 Mermaid 因果解析不作本轮算法修补。搜索、相关性和因果总输出上限均为官方 thinking/high 默认的 65536 token，包括思考。输出截断明确记为失败，保留原始证据。输入上下文以 UTF-8 字节保守上界校验官方 1M 限制，不冒充精确分词。原有 Qwen 分词器仅用于 B2 源码分页大小，所有推理角色都调用 DeepSeek。

## 费用保护

调用前读取官方 CNY 余额，用实验前 20 元余额与当前余额差作为保守扣减；并发调用在共享文件锁下预留费用。按官方高峰美元单价和 10 CNY/USD 保守预留系数计算请求余量，此系数不是实时汇率。单次请求输入按字节上界、输出按总上限估算。超时后保留不确定账单预留额，不自动重复付费。预算不足停止提交新题并保留中断记录，缺少结果与运行失败分别标记。预算保护可能在余额完全耗尽之前停止，以确保后续一次调用也在额度内。

余额差会包含同账户期间的其他调用，因此不要将它与逐请求 token 账单当作完全相同概念。官方 token 用量、缓存、思考 token、API 返回模型和后端指纹全部保留。七道金丝雀线性估算不是正式报价；能否完成 300 题取决于真实运行用量。
