## CPU复算命令

先取得上述真实冻结资产，在LocAgent根目录使用已核验环境；输出必须为新目录。以下离线命令不调用模型、不启动GPU、不重放检索工具：

```bash
source .venv/bin/activate
python -m reproduction.evaluate_extension \
  --run experiments/qwen3_rebench280_unified_v2_20261115 \
  --output experiments/qwen3_rebench280_unified_v2_20261115/reports/unified_REPLAY_NEW
```

全部280题规范化就绪前，该入口只读取公开名册、真实raw及规范化/计时回执，不打开private gold/inventory/history，也不计算暂时准确率。全部就绪后，使用同一严格`path::qualified_name`评价，失败留分母，P@5固定除以5；输出全部280题CSV、主表、Wilson/逐题bootstrap区间与同题精确McNemar，不拆执行批次成绩。

合并评价的27项CPU契约测试：

```bash
python -m unittest reproduction.test_evaluate_extension -v
```

完整工程173项测试已在正式运行前实际通过；不把随后独立审计脚本的5项边界测试冒称173项中的额外整套复跑。只读工具/失败审计的可复现脚本及命令见[审计工具说明](../../reproduction/audits280/README.md)。

## 解释边界

固定280题父池带有既有结果选择偏差；本轮只能作为该池上的开发诊断比较。通用Qwen3-8B不是作者LocAgent专用微调权重，两个sample与历史CoSIL单轨迹的采样/搜索预算也不同。工具参数通过JSON/schema检查不意味着所有值满足运行时约束，成功返回文本送达不证明全部函数源码可见或被有效使用。统一解析修正没有新增推理能力，不是完整AST/parser修复。
