## CPU离线复现命令

在LocAgent根目录，使用已冻结的同字节评分器。以下命令均不启动模型、不改历史产物；输出目录必须是新的。先执行`source .venv/bin/activate`，使用本工程已经核验的环境；不要直接在未安装这些依赖的base环境运行。

```bash
python -m unittest discover -s reproduction -p 'test_*.py' -v

python -m reproduction.evaluate \
  --run experiments/qwen3_rebench100_native_payload_v2_20261115 \
  --output experiments/qwen3_rebench100_native_payload_v2_20261115/reports/native_REPLAY_NEW
```

标准化后的诊断预测已保存，可直接用相同独立评价器逐视图复算。不得将三个目录当成三次推理或合并取高分：

```bash
python ../CoSIL/papers/SFPruner/specprune/evaluation.py \
  --predictions experiments/qwen3_rebench100_native_payload_v2_20261115/reports/final_delivery/diagnostic_scoring/compatible/predictions.json \
  --gold experiments/qwen3_rebench100_native_payload_v2_20261115/private/gold.json \
  --inventory experiments/qwen3_rebench100_native_payload_v2_20261115/private/inventory.json \
  --arms locagent --seed 20261110 --bootstrap-draws 5000 \
  --output experiments/qwen3_rebench100_native_payload_v2_20261115/reports/compatible_REPLAY_NEW
```

将上例`compatible/predictions.json`依次换成`native_replay/predictions.json`和`requested_file/predictions.json`，输出目录分别改为新目录，即可重算其他两视图。评分器SHA256固定为`22b6c4c8c24da8b88bc09c0191ffe830d5ba375183e1d98c00577007adffe5aa`。全部视图使用同一100题、R2金标和库存；所有失败留分母。

若需要从原始finish文本重新构建诊断视图，也须使用新目录，不能覆盖首次冻结的部分视图或最终视图：

```bash
python -m reproduction.postprocess_compat \
  --run-dir experiments/qwen3_rebench100_native_payload_v2_20261115 \
  --output experiments/qwen3_rebench100_native_payload_v2_20261115/audits/compat_REPLAY_NEW

python -m reproduction.postprocess_requested_file \
  --run-dir experiments/qwen3_rebench100_native_payload_v2_20261115 \
  --output experiments/qwen3_rebench100_native_payload_v2_20261115/audits/requested_file_REPLAY_NEW
```

两个程序只读本题原始输出和图、不读取金标，先生成独立视图，再由隔离评价器评分。它们保留其他原生行为，不是完整AST/parser修复；不能因分数更高而替换native主结果。

## 推理复现边界

推理入口为`reproduction/prepare.py`、`index_graphs.py`、`service.py`、`runner.py`、`worker.py`和`controller.py`。应在**新的run**准备相同公开资产、核验权重和协议，再启动服务、固定前3题金丝雀，检查隔离与通道后推进余97题；`controller.py --canary-only --keep-service`提供只跑金丝雀的入口。不能直接向历史run写入或把私有金标和历史预测挂载给worker。

当前运行已终止服务。CPU离线评价不需要重新启动GPU；重跑实际推理具有采样随机性，温度为0亦不能承诺完全确定性。推理入口复用上游LocAgent许可证；没有把模型权重或第三方数据许可合并到代码许可中。
