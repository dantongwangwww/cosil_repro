# 文件排序擂台v2：核验与结果判读

本附页解释已冻结的20条件结果，不追加参数、特征、模型或新实验；主表见[一页对比](文件排序擂台_v2_一页对比报告.md)。

1. **简单LR有有限收益，主成功线未过。** LR_noPPR的@10为220/300（73.33%），BM25为204/300（68.00%）；逐题20胜、4负、276不变，净增16题，即5.33pp。配对bootstrap95%区间[2.33,8.33]pp，但赢家在20个预注册条件中选择，区间没有多重比较校正，不能当成独立确认。未达“>10pp”线；下一步拟检查仍未入Top10的80题，不在本轮追加搜索。
2. **PPR-max未优于求和，加入PPR特征未见@10收益。** max的@10为34.00%，sum为36.67%；LR加入PPR后73.33%→73.00%，GBDT仍62.33%。这次固定配置不支持PPR的增益，不能据此证明所有调用图/PPR设计无用。
3. **预注册MMR在主指标上均下降。** 所有基础分及lambda0.3/0.5/0.7的MMR，其@10均低于对应基础排序。BM25为68.00%，三lambda分别43.33%、56.00%、66.00%；LR_withPPR为73.00%，对应组合50.67%、61.67%、68.33%。它们不是同旧版函数名Jaccard混用的结果。不要事后挑未注册lambda或只展示较不差的一项。
4. **不同指标会给出不同取舍。** CoSIL既有候选@1=47.00%、@5=63.67%；LR_noPPR为36.00%、65.00%。它的Top5只有+1.33pp，首位反而-11pp。不能用LTR的Top10/20与CoSIL最多5项的名单比较，就宣称原文件agent已整体被替代；本轮没有管线替换或端到端定位实验。
5. **种子可用性影响PPR，但这里只是描述性分层。** 229题有种子，其PPR-max@10=101/229（44.10%）；71题无种子，仅1/71（1.41%）。后者全零分按路径同分顺序，不能当真正个性化排序。两组issue本身可能不同，不能把差值当成只改变种子的因果效应。分层覆盖全部20条件，未用于调参或改成功线。
6. **不能按本轮宣称“排序非瓶颈”。** 按预注册解释，非随机实质排序臂@10极差55.67pp，未达<3pp。反过来也不能据此证明排序是唯一瓶颈；后续函数探索、剪枝与输出解析尚未在本组测量。固定GBDT落后于LR，没有额外训练曲线证据，不能直接判定过拟合或断言树模型固有较差。
