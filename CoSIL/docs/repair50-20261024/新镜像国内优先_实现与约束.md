# 本轮新镜像国内优先：实现与约束

2026-10-25，依据用户希望使用国内网络的要求，仅调整尚未开始准备的新镜像的运输偏好。选题、官方资格、模型、提示词、评分和5美元API上限不变。

## 已验证的依据

instructlab/sdg-461 的独立HTTP1恢复已真实成功，完整归档7,438,289,408字节，全部压缩层SHA、实际解压diffID及Docker身份通过。旧56份证据保持不变，独立进程退出0，已登记自有镜像lease。同题资格父于09:43:20 UTC恢复；正式50题尚未冻结，已通过21题，修复API调用为0。

这只能证明本次条件下运输成功，不能证明此前所有失败均由HTTP/2导致。

## 本批计划

1. 增加操作方显式激活、仅本run有效且不可覆盖的私有策略回执，固定1ms入口、HTTP1_ONLY、匿名及禁代理。不修改共享Docker配置或系统代理。
2. 保持资格阶段现有官方manifest pin；镜像站必须按同一canonical摘要返回完全匹配的manifest。禁止用镜像站latest替代官方版本。
3. 所有旧成功、失败、恢复、缓存和归档路径优先处理。策略只适用于真正fresh的稳定digest目录：尚无归档、下载日志、attempt或初传状态；可已有相同官方manifest回执。已运行任务不切换。
4. 复用完整已验证donor及私有新缓存；没有donor时可使用空缓存。仅新probe/pull子进程固定HTTP/1.1和国内入口。保留1800秒、磁盘余量、全部SHA/实际diffID/加载身份与所有权检查。
5. 国内首传失败落盘并停止，不自动切回官方、不换题、不隐式进入16MiB官方小尾恢复；原官方路径的小尾规则保持不变。
6. 成功后按原正常路径本地复用或离线重载，清理的仅为本批已完整验证且可从完整归档重建的新缓存。旧失败证据、日志、模型、历史结果和封存数据不动。

## 校验读取性能审计的边界

只读代码与文件大小审计估计，当前这个包含多次历史失败的特殊H1成功路由，一次cached校验会重复处理约172.72GB逻辑文件内容；这不是物理磁盘读取量或延迟实测。单次作用域内按文件stat复用验证结果有潜在性能收益，但不能在所有并发mmap写入等情形下声称与多次完整hash严格等价。本批不实现此优化，保留既有前后完整SHA口径。后续fresh正常路线没有该特殊历史失败树。
