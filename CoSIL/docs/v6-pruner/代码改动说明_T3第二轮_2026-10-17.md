# T3第二轮代码改动说明

本批改动依据用户2026-10-17新指令。新增/大改前的现有代码、文档已推送到用户GitHub：
[52c8e30764407b2d8346bd0a502301986c7e63ca](https://github.com/dantongwangwww/cosil_repro/commit/52c8e30764407b2d8346bd0a502301986c7e63ca)。
已从远端重新读取提交，逐一核对55个新增/变更文件与修改前快照一致。

本轮新增独立的`code_v6_round2/`，原`code_v6/`、首轮结果、T2冻结数据及v5历史报告保持原样。

| 文件 | 改动及目的 |
|---|---|
| `common.py` | 独立第二轮命名空间、历史文件核验及沿用gold保护优先顺序 |
| `prepare.py` | 仅重求train的sample_weight：正负总质量1:2→1:1，三项条件来源占比按T2同法对齐val；冻结新派生数据和二轮晋级规则 |
| `train.py` | 从已冻结首轮训练器复制，隔离路径、阶段及授权；seed0训练数学/顺序不变，新增获授权的seed1/2重复入口；7B沿用首轮成功的90%分配上限 |
| `diagnostics.py` | CPU扫描安全low*，处理p≤low包含等号的边界；安全阈值独立于正式0.6资格门 |
| `run.py` | 持久调度4B优先、0.6B对照、SweRank最后；按预注册CI/点估计/失败三分支交付，必要时做seed稳定性重复 |
| `report.py` | 自动生成两轮并排总览、逐题分析、逐函数CSV；以issue/function ID对齐，未完成留NA |
| `checks.py` | CPU逐条验证8556个train仅权重变化、val字节不变、条件配比相等，以及安全阈值浮点边界 |

相对首轮，正例权重×1.5、负例×0.75，均值仍为1。模型从原公开底座新建LoRA，非接着首轮adapter训练；rank16/alpha32/dropout0.05、lr5e-5、3epoch、seed0、effective batch8等均保持。
仍按首轮每8例的加权loss归一化执行优化；没有另换loss或优化器。资源路径、阶段标记与7B成功显存上限属于部署隔离，不是新增训练变量。

晋级候选只来自各底座按原规则选出的checkpoint，不通过挑选另一个epoch满足点估计来换选模规则。CI资格仍要求区间有定义且非退化；点估计双达标仅获得“可行性”身份，不改写CI不通过的事实。CI候选的seed1/2使用相同配方，预注册为两个重复均通过原CI门才视为稳定；不在重复间择优掩盖失败。

low*选自同一val，其0个gold直剪是阈值构造结果，不能当作泛化安全证明。v5/v6数据轴收益也不能由不同val群体间的数字直接归因；CI能否通过依赖具体issue聚类分布，不能仅由76个gold推出一条普适的5/76界线。

金丝雀的后续边界：本指令授权符合条件后的默认阈值/安全阈值双臂，但同时禁止改变vLLM。T1主Qwen服务已按原授权关闭，本轮不擅自重启；候选及双阈值先冻结落盘。进入实际管线前还须使用v6长输入和直接调用邻居，禁止复用v5的2000/1500截断冒充v6实验。
