## T0：截断分诊审计 + Qwen 实测锚（零 GPU，立即开始）

**T0-a 截断分诊**。背景：模型输入被截断为 issue 前 2000 字符、候选函数前 1500 字符；C 类正例中 train 521/1053、val 71/87 缺完整显式调用证据。该现象混着两个病因，疗法不同，先拆比例：

- **病因 A（截断）**：调用关系代码行存在于该函数完整源码中、但落在前 1500 字符之外 → 放宽截断可治。
- **病因 B（证据在外部）**：该函数自身源码（任何长度）不含对 gold/邻居的显式调用，关系在别的文件里 → 需加邻居摘要行。

做法：对上述"证据不可见"正例逐条取完整源码（结构文件/仓库可溯），定位调用行位置，分入 A/B（或两者：截断内不可见但外部也仅间接）。产出：**两病因比例表（train/val 分列）+ v6 输入层处方建议**（放宽到多少字符 / 是否需要邻居摘要行 / 各自覆盖多少比例）。顺手项：issue 侧同样审一遍——issue 前 2000 字符截掉的部分是否含函数名/关键症状描述，给比例。

**T0-b Qwen 实测锚**。背景：原资格门 0.80 的锚"Qwen 单独判决粗估~0.75"从未实测。做法：在 v3c/旧版 pruner 历史日志中，提取 Qwen 对 val 363 对（以及 C 轮 714 对中可配对者）候选函数的真实判决，计算 Qwen 零样本的 accuracy / AUC / gold 误剪率。**先报覆盖度**（val 对中有 Qwen 历史判决的比例）；覆盖 <50% 则如实说明、此锚降级为部分实测。此数字将进 v6 资格门当第一根锚，也会进论文（"被替换者的真实水平"）。

## T1：金丝雀——B 版 reranker 插管线（已放行，2026-10-16 用户批准）

**用户已批准放行。** 按以下冻结协议执行，协议本身不再改动：

- **模型**：B 覆盖过滤版 Qwen3-Reranker-0.6B（rank8/dropout0.1，best epoch1，现有 checkpoint，不重训）。
- **路由（hybrid 模式）**：温度校准（val 拟合，参数落盘披露）+ low=0.6 / high=0.9：p≤0.6 直剪、p≥0.9 直留、灰区交现行 Qwen pruner。另设 small 臂（全部由小模型判决）作对照。
- **规模**：20 题 × 3 臂（off 对照 / hybrid / small）= 60 runs。题集分层抽样（gold_named / other_named / no_name 按全池比例），抽样种子落盘。off 臂优先复用 v3c 对应题结果，协议一致性核对不过则补跑。
- **判读**：主终点=函数级 Top-5 相对 111/293=37.88% 基线不显著下降（McNemar）；次终点=pruner 相关 token 账（对 v3c 口径）、灰区比例、单次判决延迟。安全终点=gold 直剪行为与 v3c 日志对照。
- **止损线**：Top-5 掉超 3pp 即停，保现场等指令。
- **强制披露**（报告里写明）：①温度校准与阈值在同一 val 上拟合；②金丝雀题目与训练数据同源（同 300 题轨迹）→ 结果偏乐观，仅当可行性证据，不当论文主证据；③单 seed。
- **天然安全下界**：最坏情形灰区全交 Qwen，行为退化为现行 pruner——若观察到比基线更差超过噪声，优先怀疑集成 bug 而非模型。

## T2：数据 v6 重建 + 新资格门冻结（等 T0 报告）

三层各自的处置（v5 五轮买来的教训，全部一次性、有边界）：

- **标签层：不动。** B 轮双证据基底原样保留；C 轮已采完的 Verified 186 题运行时覆盖（88 题合格）**直接复用**——扩挖成果不作废，只是不再按 C 的配比用。
- **输入层：按 T0 处方执行。** 候选：issue 2000→8000 字符或全文；函数 1500→8192 字符；病因 B 占比高则加邻居摘要行（"本函数被 X 调用 / 调用了 Y"，从结构文件生成，格式示例先报审再批量）。
- **分布层：三对齐。** C 轮败因是训练分布被带离部署分布，v6 按部署场景配平三组占比：D-only 负例（C 轮 train 51.02% vs val 26.05%）、C 类代理正例（87.17% vs 68.07%）、gold A/B 正例（12.83% vs 31.93%）。手段=降采样/加权，不新造数据。目标：train 与 val 的三组占比差 ≤10pp，实际可达性报告说明。

**新资格门（训练开始前冻结公布，取代 0.80/0.85 双门）**：

1. 实测对手锚：val accuracy ≥ T0-b 实测 Qwen 成绩 + 2pp（无实测则此条降级为报告项）；
2. 部署风险锚：温度校准 + 0.6/0.9 路由下 **gold 直剪率 ≤15%**（按 issue 聚类 bootstrap 95% CI 上界判定）；
3. 命题锚：混合集剔除 precision ≥0.85（CI 下界判定，口径沿用 10-13 裁定）；
4. AUC 改为报告项不设硬门；三项主锚全部以区间判定，不用点估计。

最终裁判权在金丝雀端到端（非劣效检验），离线门只是初筛——此句写进报告。
