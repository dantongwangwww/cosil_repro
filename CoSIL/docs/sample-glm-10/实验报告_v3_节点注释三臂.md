## 二、四个发现

### 发现 1：实验的主对照被"早退"搅了局——但搅出了新发现

新版原生 function calling 本指望消灭旧版格式夭折，结果 glm-4-flash 换了个死法：**tool_choice=auto 时，模型第一轮有 40-50% 概率直接给出答案文本而不发起任何工具调用**（插桩 no_tool_call 事件全程记录）。这是服从性问题的另一面：不是"格式吐错"而是"压根不干活"。搜索没跑起来，注释臂的召回对照就失去一半样本。

### 发现 2（意外信号）：注释让模型"愿意干活"

on 臂早退 2/10（off 5/10）、工具调用 137 次（off 67 次）——**有注释时模型探索量翻倍、早退减半**。更有意思的是 shuffled（错位注释）也部分复现了这个效应（早退 4/10 但 11001 上 fetch 到了 gold）：暗示起作用的可能不是注释的语义内容，而是**"节点清单有了可读信息→模型不再秒答→开始探索"**的机械效应。单 run 方差下这只是假设，但它与发现 3 合起来指向同一个机制。

### 发现 3：症状固着的搜索期形态——gold 函数几乎从不被 fetch

9 个可测问题 × 3 臂 = 27 个 run，fetch_gold 只发生 2 次（11001 的 `__init__`，on 与 shuffled 臂各一次）。模型围着症状区域调工具（12907 全在 CompoundModel、10914 全在 uploadhandler），**根因节点连被看一眼的资格都没拿到**。实验二证明"看见了也选不对"（症状固着），实验三补上另一半：**搜索期根本走不到看见**——症状固着在搜索期的形态是"探索轨迹被症状名字锚定，从未游到根因邻域"。

### 发现 4：影子陪审的稳定供词——准则自认"文本相似度"

影子理由跨臂一致地供出判决准则："文本相似度与报告中的描述相似……命名上 `replace` 与报告一致，因此判定相关"。**模型自己承认在按相似度办案**——这是"语义相关绑架因果相关"的第一人称证据，将来写论文可直接引用（示例在 prune_logs_v3/*/shadow 事件）。

## 三、结论与下一步

1. 节点注释的"语义增益"未获支持（fetch_gold 几乎全灭），但"探索激活效应"是意外的正面信号——需多 run 复验；
2. 真正的第一瓶颈前移到**搜索存活**（早退 40-50%）：一行级修法是把 `tool_choice` 从 auto 改 required（强制首轮必须调工具）——这是 CoSIL 的设计参数，值得作为实验三 b 单独测；
3. 影子陪审机制全程零干扰运行成功——"想看理由不污染判决"的解法可复用。

## 四、局限

单 run × 单模型 × 10 题；15/30 run 被截断（无最终输出，但事件日志完整）；注释覆盖为候选文件函数（2468 条，gold 文件全覆盖）；on 臂 token 成本≈off 的 1.5-2 倍（探索量翻倍所致）；最终命中指标因截断不可比，本报告以 fetch_gold 为主指标。
