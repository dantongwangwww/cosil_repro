## 研究问题和实验臂

研究问题：在相同 issue、候选函数及原搜索实际访问集合下，LoRA 任务微调与直接调用邻居信息分别如何改变函数相关性判别和三路路由？

| 臂 | 权重 | 输入 | 分数来源 |
|---|---|---|---|
| `full` | 固定 Qwen3-Reranker-4B + 原 epoch1 LoRA | 原完整 v6 | 历史原始 logits；不冒称本批重新推理 |
| `no_lora` | 同一固定 4B 底座，不使用 LoRA | 与 full 相同 | 本批真实 forward |
| `no_neighbors` | 与 full 相同的 epoch1 LoRA | 删除调用邻居边行，保留固定 header | 有边输入本批真实 forward；自然无边且输入哈希相同者复用原分数 |

`no_neighbors` 保留原 issue、function、XML 包装和固定邻居 header 字节，重新生成 model_input 及 SHA；不使用释放的预算扩展正文。该臂是推理时输入消融，不能表述成“无邻居训练模型”。完整方案已训练于含邻居输入，结果反映该部署模型对邻居信息的依赖，不能排除训练/推理分布变化。自然无邻居样本是输入不变的阴性对照；若全部重评分，也须报告这些样本的新旧 logit 差异，不能只展示有利样本。

执行请求表在评分前按输入哈希确定：`no_lora` 1055次新forward；`no_neighbors` 758次新forward（val356、runtime402），另297条自然无边样本（val131、runtime166）因模型和输入不变复用full。合计1813次组件forward，探针另计。复用行必须显式注明历史来源与原因；不能称全部2110条变体分数都是新增推理。

冻结底座 revision、适配器 SHA、tokenizer、BF16、SDPA、answer-logit 模板及 yes/no 两 token 的评分方式。全部变体记录环境、输入/模型哈希、实际 forward 数、输入 token 和评分耗时。运行环境差异与数值非确定性仍可能造成差异；历史 full 的时延不得与本批单模型评分耗时作受控在线速度比较。

正式新评分前，执行 full 历史分数兼容性门：在合并的 val/runtime 唯一输入上，以来源输入SHA升序取最小12条，再取原生输入token数最长4条（并列按SHA排序），合并去重，最多16条。选择不读标签或新分数。用完整LoRA真实重新评分，比较历史logit差、历史冻结温度后的概率和路由；每条绝对logit差≤0.05且路由完全一致才允许正式复用full历史分数。校准概率差如实报告但不另设事后门槛。超门即停止，先分析漂移，不能反复选取有利运行。该门只说明有限输入上的数值复用兼容性，不证明所有输入或硬件位级等价。探针不计入组件消融样本数或正式请求量。

## 样本和对齐

1. val 为原 44 个 issue、487 个唯一 issue/function 对，含 gold_AB 76、C_positive 162、D_only_negative 33、E_negative 216。所有模型使用同一标签和组别；val 样本等权，不使用训练 sample_weight。
2. 外部固定访问集来自既有 100 题、100 仓库实验的 full 路径，共 652 次函数评分、568 个唯一输入。完整100题名册、92个函数合格题、原99完整配对状态保留为来源描述，不变成新增推理分母。
3. 对齐键为 `(split, instance_id, function_id, source_input_sha256)`，禁止按文件行号拼接。变体输入另有自身 `input_sha256`；full/no_lora 应与来源相同，no_neighbors 可不同。
4. 同一唯一输入的重复历史访问先保留为事件，再明确去重。唯一函数键为 `(instance_id, function_id)`；同一函数若有多个输入，额外报告输入数，并以“至少一次拒绝/灰区/保留”分别计数，不能使三项强行互斥。
5. 运行 gold 仅指 R2 `COMPLETE_NONEMPTY`、set_complete 且非空的既有完整修复目标，按精确函数身份判定。非目标函数没有通用语义负标签，禁止据此计算 runtime accuracy、AUC 或拒绝 precision。无合格函数真值的题另列。
6. 不根据新分数选择样本、不删除异常结果；缺分数或非有限 logits 使分析失败并留下错误，不能伪造为拒绝或保留。

## 校准和路由

主要比较采用各臂独立、相同算法的 val 校准：用所有487条原始 logit 差 `d=logit_yes-logit_no`，在 `T∈[0.01,100]` 上最小化等权二分类 NLL，精确复用 `specprune.metrics.fit_temperature`。full 校准参数使用历史冻结 `T=2.9846201034621833`，并重算验证一致性；其 Python 浮点实现差异应如实记录。

各臂 `p=sigmoid(d/T)`；低阈值统一定义为 `nextafter(min(p of val gold_AB), -infinity)`，高阈值统一为0.9。`p≤low` 直剪，`p≥high` 直留，其余升级。若 low 不满足 `[0,0.9)`，记录该臂校准协议不适用并停止，不能人为调低 low 或改 high。浮点 sigmoid 下溢导致 low<0 同样记录为不可部署，不能悄悄改变规则。

原 full low 为 `0.12947567721292427`。该规则构造出 val gold 零直剪，因此其零值是经验约束，不是独立验证或总体安全保证。温度/阈值与性能在同一 val 上估计，校准指标是样本内诊断，不宣称校准泛化改善。

同时输出 `same_frozen_threshold` 诊断：各臂均使用 full 的 T/low/high，显示直接替换评分组件而不重新校准的结果。此诊断不能作为主要公平比较，也不能将其差异全部归因于微调/邻居能力；主要结果和此诊断须分表，列出实际 T、low、high。

## 统计指标

val 原始判别：ROC AUC（并列分数计0.5）、accuracy@0.5（等价于原始 logit≥0）；同时列TP/FN/FP/TN。校准诊断：稳定 logit 计算的 NLL、Brier、固定10个等宽概率箱的 ECE，提供校准前后和各箱样本数。

val 路由：全体、gold_AB、所有正例、所有负例、E_negative 分别列拒绝/灰区/保留数与相应组内分母；拒绝 precision 使用真实 val 标签。没有任何拒绝时 precision 为 NA，不记作100%。

runtime 路由：分别列全部访问、唯一输入、唯一函数和 issue 级计数；对合格 R2 目标另列直剪/灰区/直留。目标函数/issue 级使用“至少一次发生该路由”指标，并列任一路由重叠情况；重复访问不视作独立观测。未访问目标不得计作“安全保留”，须列“合格题中无目标访问”的数量。

配对不确定性：仅对两个新增臂相对 full 的 val AUC 差和 accuracy 差给出主要95%百分位区间。按44个 issue 成簇、有放回抽取44簇，保留抽中 issue 内全部函数和两臂配对，2000次，seed=20261114。同一抽样序列用于所有臂；不把函数对当作独立抽样单位。单一标签的重采样令 AUC 不定义，跳过该次 AUC 并报告有效次数；accuracy 保留。区间使用排序样本的 `ceil(.025*n)-1`、`ceil(.975*n)-1` 索引。区间针对原始判别指标，不在 bootstrap 内重拟合 T/low；校准/路由结果只作描述。两项变体×两项指标共4个探索性比较，区间不作多重性校正，不以“显著”或“不显著”代替效应量，也不据区间包含零声称等效。

## 另列策略重放

可对 full 历史分数预先固定 `p<0.5→reject, p≥0.5→retain` 做“无灰区二分类策略重放”附表，其他函数身份/类回退不在本离线访问集内。它没有新增模型推理、没有8B判断、没有重新搜索。此表必须与真实组件消融分开，不能声称测量了去灰区后的定位性能。

## 结论边界和论文用语

本批可称“固定候选访问条件下的离线组件消融”：两个删减臂产生真实新分数，完整臂复用经过哈希核验的原分数。它回答相同候选输入上的判别和路由变化；val 有监督诊断与外部100题历史访问分布互为补充，但均不是封存 test。

访问集合由 full 原搜索路径选择，可能偏向完整方案；组件变动会改变未来搜索轨迹，而本实验冻结了这一反馈。因此不新报 Hit@k、主模型总 token 节省、端到端时延或对最终定位质量的因果改善。原端到端结果仍归属于原 baseline/full 100题实验，不能将离线重新评分嫁接为新定位结果。

允许的表述：“在同一487个验证对上，去除X后AUC变化为…，issue簇配对95%区间为…；在完整方案历史访问的568个唯一输入中，按各自val校准规则，目标函数直剪数由…变为…。”

不允许的表述：“消融证明微调/邻居提高最终定位率”“节省若干主模型调用/token”“零直剪证明安全”“非目标函数均为负例”“652次访问是652个独立样本”。
