## 一、克隆与两个必改的坑

```bash

python CoSIL/fl/CoSIL_localize_func.py \
  --output_folder results/full --output_file loc_func_full.jsonl \
  --loc_file results/full/loc_out_full.jsonl \
  --num_threads 8 --model openai/llama3 --skip_existing --temperature 0.0 \
  2>&1 | tee /home/wdt/new_full_func_log.txt
```

预计耗时：文件级与旧版相当（~1小时）；函数级**可能比旧版慢**（侦查式 pruner 每次判决前多至 3 轮工具调用 = 更多 LLM 交互），预留 1.5-2 倍时长。

## 五、与旧版结果的对照分析

跑完后拖回两个 jsonl（命名 `qwen7b_新版_full.jsonl` / `qwen7b_新版_func.jsonl`），我做四件事：

1. **四指标对齐计算**（与旧版同口径：Top-1/3/5、MRR、hunk 金标）
2. **配对比较**：300 题哪些题新版对旧版错/反之，差异题的特征归因（侦查 pruner 立功 or 原生 FC 立功 or 均非）
3. **pruner 行为对比**：新版判决分布 vs 旧版 True:False=764:1043 的基线
4. **2×2 矩阵完成表**：旧×GLM / 新×GLM / 旧×Qwen / 新×Qwen 四格数字并排
